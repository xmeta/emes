= EMES
:toc:

EMES (Executable Mechanical Engineering Specification) is an AI-native architecture for describing, generating, verifying, and iterating mechanical mechanisms as structured, version-controlled engineering data.

== Core idea

CAD is a derived artifact, not the source of truth.

[source,text]
----
requirements + design intent
          |
          v
 semantic mechanism IR
          |
    +-----+------+----------------+
    |            |                |
    v            v                v
  CAD         simulation       BOM / DFM
    \            |                /
     +-----------+---------------+
                 v
       deterministic evidence
                 |
                 v
        AI / optimizer patch
                 |
                 +------> repeat
----

The canonical source records requirements, topology, parameters, interfaces, load cases, objectives, constraints, and analysis intent.
Generated CAD, simulation models, solver decks, reports, and BOMs remain reproducible projections.

== Current status

Phase 1 architecture is being established under Issue #1.

The initial executable slice uses a JSON canonical IR with schema and semantic validation.
A custom EMES language is intentionally deferred until concrete examples prove it is necessary.
